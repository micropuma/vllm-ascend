### 优化效果汇总

| 场景 | Δ 吞吐 | Δ TTFT | 结论 |
|------|--------|--------|------|
| **Qwen3-30B (dbo_fc1)** 🔥 | **+34.4%** | **-26.2%** | 🔥 **全场景最高提升** |
| DeepSeek TP (dbo_fc1) | +25.8% | -20.5% | 🔥 最优 DeepSeek 组合 |
| DeepSeek DP Shared (dbo) | +1.1% | -21.5% | ✅ 正向（TTFT 大幅优化） |
| DeepSeek DP (dbo) | +8.7% | -0.6% | ✅ 正向 |
| DeepSeek TP (dbo) | +8.0% | -7.7% | ✅ 正向 |
| DeepSeek TP (dbo_fc1_aiv) | +3.5% | -2.6% | ✅ 正向 |
| DeepSeek TP (dbo_fc2) | +0.8% | -0.2% | ➡️ 微弱 |
| DeepSeek 小批次 (dbo) | -2.4% | +7.8% | ❌ 退化 |
| Qwen3-30B (dbo) | -5.1% | +5.5% | ❌ DBO 单独退化，加 FC 后反转 |

### 结论

1. **Qwen3-30B + FlashComm 效果远超预期**：手动补测显示吞吐 +34.4%，延迟 -26.2%，是全场景最高提升。auto_benchmark 中超时导致漏测，实际优化效果巨大
2. **dbo_fc1 是 DeepSeek TP 最优组合**：+25.8% 吞吐提升，DBO 与 FlashComm1 高度互补
3. **DBO 在 DP 场景持续受益**：dp_dbo +8.7%，dp_shared_dbo TTFT -21.5%
4. **FlashComm1 的收益比 DBO 更稳定**：Qwen DBO 单独退化 -5.1%，加上 FC1 后反转为 +34.4%。FC1 才是当前最可靠的加速手段
5. **小批次不适合 DBO**：额外开销超过收益，建议通过 `DBO_PREFILL_TOKEN_THRESHOLD` 控制触发门槛
6. **auto_benchmark qwen_fc1 超时需排查**：手动可启动成功，可能启动超时阈值偏短或首次编译时间过长
